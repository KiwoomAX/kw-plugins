# 계산 이전 안내

엑셀 수식을 표 · 열 이름 기준의 Python 코드 `calc.py` 로 옮기는 규칙이다. 결과표와 함께 소계 · 합계도 처음부터 이 코드가 통계 표로 계산한다.

## 모양

`calc.py` 는 함수 하나를 제공한다.

```python
def calculate(tables: dict[str, list[dict]], base_date: date) -> dict[str, list[dict]]:
    ...
```

- `tables` 는 `{표 이름: 행 목록}` 이다. 원본 엑셀 파일은 읽지 않는다.
- 돌려주는 값은 `{대상: 행 목록}` 이다. 결과표 행에는 `row_seq` 를 넣는다. `row_seq` 는 표 정의의 데이터 행 순서(제목 · 소계 행 제외)이고, 대조는 이 순서로 엑셀 행에 맞춘다. 결과표 행에는 소계 · 합계 행을 넣지 않는다.
- 통계 표는 같은 반환값 안에 통계 표의 대상 이름(`table_plan.json` 에서 단계가 `stat` 인 표 이름의 마지막 부분, 표 정의 소계 항목의 `target`)으로 돌려준다. 행마다 소계 항목의 이름 글자 열(`label_col`)에 엑셀의 이름 글자(예: 「소계」), 묶는 열(`group_by`, 여러 개면 각 열)에 묶음 값, 값 열(`values`)에 계산한 값을 넣고, `row_seq` 는 통계 표 안의 행 순서다. 대조는 이름 글자와 묶음 값으로 엑셀 소계 행을 찾아 같은 열의 셀과 맞춘다.
- 날짜가 열로 펼쳐진 결과표는 `{대상}_dates` 에 `t_plus_N` 열의 실제 날짜 한 행을 함께 돌려준다.
- 입력의 소수와 날짜는 글자로 온다. 계산 코드 첫머리에서 숫자와 날짜로 바꾼다.
- 파이썬 `round` 는 쓰지 않는다. 사사오입이 필요하면 `colmap.round_half_up` 과 같은 방식으로 계산한다.

## 옮기는 순서

1. 결과 파일(`explain_results.json`)의 `definitions` 로 표 범위를 찾고, 엑셀에서 원천 표, 계산된 표, 결과표 순서로 수식을 읽는다. 소계 · 합계 행의 수식은 통계 표 계산으로 옮긴다.
2. 역할이 「계산」인 표는 계산 코드 안에서만 만들고 저장하지 않는다.
3. 열 규칙에서 벗어난 셀(값을 직접 적은 셀, 예전 날짜 파일을 참조하는 셀)은 개발자에게 보이고 일반화, 고정값(override), 이전 결과 참조, 수기 입력 표 중에서 고르게 한다. 담당자가 운영 중에 값을 직접 적는 셀이 늘어나는 표(예: 새 펀드가 들어올 때마다 조정값을 적는 열)는 고정값으로 두면 개발자가 매번 고쳐야 하므로, 그 값을 수기 입력 표로 두고 담당자가 입력 양식으로 올리게 한다.
4. override 를 고르기 전에 그 값을 WINUS 원천 표에서 가져올 수 있는지 확인한다. 가져올 수 있으면 계산 규칙으로 대체한다.
5. 새 펀드 행이 와도 계산이 멈추지 않게, 찾지 못한 키는 빈 값으로 처리한다.

## 대조

`scripts/verify_calc.py` 가 엑셀 저장값을 샌드박스가 돌려주는 모양으로 바꿔 `calculate` 에 넣고, 셀의 표시 자릿수로 대조한다. 합격이면 종료 코드 0 이고, 다른 셀과 빠진 셀, 다른 소계 칸과 빠진 소계 행은 결과 파일에 적힌다.
