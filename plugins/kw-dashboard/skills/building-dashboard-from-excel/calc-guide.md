# 계산 이전 안내

엑셀 수식을 표 · 열 이름 기준의 Python 코드 `calc.py` 로 옮기는 규칙이다.

## 모양

`calc.py` 는 함수 하나를 제공한다.

```python
def calculate(tables: dict[str, list[dict]], base_date: date) -> dict[str, list[dict]]:
    ...
```

- `tables` 는 `{표 이름: 행 목록}` 이다. 원본 엑셀 파일은 읽지 않는다.
- 돌려주는 값은 `{대상: 행 목록}` 이다. 결과표 행에는 `row_seq` 를 넣는다.
- 날짜가 열로 펼쳐진 결과표는 `{대상}_dates` 에 `t_plus_N` 열의 실제 날짜 한 행을 함께 돌려준다.
- 입력의 소수와 날짜는 글자로 온다. 계산 코드 첫머리에서 숫자와 날짜로 바꾼다.
- 파이썬 `round` 는 쓰지 않는다. 사사오입이 필요하면 `colmap.round_half_up` 과 같은 방식으로 계산한다.

## 옮기는 순서

1. 분석기의 결과 화면에서 원천 표, 계산된 표, 결과표 순서로 수식을 읽는다.
2. 역할이 「계산」인 표는 계산 코드 안에서만 만들고 저장하지 않는다.
3. 열 규칙에서 벗어난 셀(값을 직접 적은 셀, 예전 날짜 파일을 참조하는 셀)은 개발자에게 보이고 일반화, 고정값(override), 이전 결과 참조 중에서 고르게 한다.
4. override 를 고르기 전에 그 값을 WINUS 원천 표에서 가져올 수 있는지 확인한다. 가져올 수 있으면 계산 규칙으로 대체한다.
5. 새 펀드 행이 와도 계산이 멈추지 않게, 찾지 못한 키는 빈 값으로 처리한다.

## 엑셀 열과 WINUS 열

이름이 달라도 값으로 맞춘다. `colmap.match` 는 키 열로 행을 맞춘 뒤 열마다 값이 가장 많이 일치하는 응답 열과 변환을 찾는다. 빈 값은 0 으로 보고, 둘 다 빈 열은 이름으로 맞춘다.

## 대조

`verify_calc.read_table` 로 엑셀 저장값을 읽고 `verify_calc.wire_values` 로 바꿔 `calculate` 에 넣는다. 표시 자릿수는 `verify_calc.display_digits` 로 읽는다. 결과를 `verify_calc.compare` 로 대조하고 `verify_calc.passed` 가 참이어야 다음 단계로 간다.

- 숫자는 셀의 표시 형식 자릿수로 반올림해 같으면 같다고 본다.
- 엑셀이 `#REF!` 인 셀은 따로 세고 합격 판정에서 뺀다.
- 엑셀 저장 뒤 WINUS 값이 바뀐 셀은 개발자에게 보여 확인받는다.
- 소계 · 합계 식과 날짜 머리글도 함께 대조한다.
