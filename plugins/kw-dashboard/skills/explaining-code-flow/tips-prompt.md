# 알아 둘 점 지침

이 지침은 분석 서브에이전트가 장면마다 「알아 둘 점」을 코드에서 찾는 방법을 정한다. 「알아 둘 점」은 안내 화면의 오른쪽 남색 상자에 크게 표시되며, 화면을 쓰는 사람이 숫자와 색과 표시를 잘못 읽지 않게 한다.

## 찾을 내용

서브에이전트는 장면의 화면 코드에서 아래 종류의 규칙을 찾는다.

- 색의 뜻: 어떤 조건에서 어떤 색으로 표시하는지
- 표시 조건: 배지 · 표시가 붙는 조건(예: 올라온 지 2일 이내면 New)
- 단위와 기준: 금액 단위, 기준일, 정렬 순서, 최대 표시 개수
- 예시 값 여부: 화면의 숫자가 코드에 적어 둔 샘플 데이터인지
- 갱신 시각: 자동 수집이나 새로고침이 언제 값을 바꾸는지

내부 수치(동시 처리 건수, 재시도 횟수)와 개발자만 쓰는 설정은 넣지 않는다.

## 근거

항목마다 근거 `파일:줄` 을 적고, 근거를 찾지 못한 항목은 내지 않는다. 주석과 코드가 다르면 코드를 따르고, 그 차이는 `analysis-prompt.md` 의 `mismatches` 에 적는다.

## 문장 규칙

`analysis-prompt.md` 의 「문장 규칙」 표를 그대로 따른다. 항목은 한 문장으로 쓰고, 「~합니다」체로 끝내며, 색은 색 이름과 뜻을 함께 적는다.

시제품의 예시는 아래와 같다.

| 알아 둘 점 | 근거 |
|---|---|
| 분홍색(마젠타) 숫자는 증가, 파란색 숫자는 감소, 검은색 숫자는 변동 없음을 뜻합니다. | `components/Delta.tsx:2-11`(주석은 0 을 회색이라 적지만 코드는 검은색 글자를 쓴다) |
| 운용사 선정 공고가 올라온 지 2일 이내면 제목 옆에 New 표시가 붙습니다. | `components/tabs/HomeTab.tsx:259`, `components/tabs/HomeTab.tsx:290-292` |
| 자동 수집은 매일 오전 9시(한국 시간)에 새 글을 모읍니다. | `vercel.json:2-5` 의 `0 0 * * *`(UTC) |

## 출력

`analysis-prompt.md` 의 출력 JSON 에서 장면의 `tips` 목록에 문장을 넣고, 근거는 아래 형태로 같은 JSON 의 `tipsEvidence` 에 둔다.

```json
"tipsEvidence": {"0.0": ["vercel.json:2-5"], "1.0": ["components/tabs/HomeTab.tsx:259"]}
```

키는 `"<장면 번호>.<항목 번호>"` 다. 주 세션은 결과를 받은 뒤 근거 줄을 열어 모든 항목을 대조한다.
