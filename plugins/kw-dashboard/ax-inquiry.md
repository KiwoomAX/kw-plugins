# AX 팀 문의 안내

스킬이 AX 팀에 요청이나 문의가 필요하다고 할 때 이 문서대로 안내한다. AX 팀은 요청을 AX 지원 문의 서비스로 받는다.

| 항목 | 값 |
|---|---|
| 주소 | `http://192.7.9.45:9999` (사내망, 사내 계정으로 로그인) |
| 첫 화면 | 문의하기 양식. 로그인을 거치면 주소 뒤의 경로가 사라지므로 늘 첫 화면 주소로 안내한다 |

## 안내 순서

1. 사용자에게 AX 팀 문의가 필요하다는 사실과 이유를 알린다. 하던 작업에서 무엇이 멈췄는지, AX 팀이 해 줄 일이 무엇인지 한두 문장으로 적는다.
2. 아래 「안내 문구」 형식으로 고를 문의 유형과 양식에 붙여 넣을 내용을 준다.
3. "문의 화면을 열까요?" 라고 묻는다. 그렇다고 하면 아래 명령으로 기본 브라우저를 연다. 아니라고 하면 열지 않는다.

   ```powershell
   Start-Process 'http://192.7.9.45:9999'
   ```

4. 문의는 사용자가 양식에서 직접 보낸다. Claude 는 대신 보내지 않는다. 그다음 동작(멈출지, 다른 단계를 이어 갈지)은 이 문서를 연 스킬이 정한다.

## 문의 유형

부르는 스킬이 문의 유형을 정해 준다. 정해 주지 않았으면 아래 표로 고른다.

| 문의 유형 | 고르는 상황 |
|---|---|
| 데이터 조회 요청 (화면·엑셀·테이블) | 필요한 데이터를 읽는 등록 쿼리가 없어 새 쿼리 등록이 필요할 때 |
| 제공 인프라 | 저장소·화면 권한, 셸 변경, 포트·경로 등록, 샌드박스 공간처럼 AX 팀만 바꿀 수 있는 설정이 필요할 때. 다시 해도 계속 실패하는 서버·도구 오류를 알릴 때 |
| 기능 검토 문의 | 직접 만든 기능의 검토·배포·대시보드 이관을 요청할 때 |
| 환경변수(env) 등록 | 배포할 서비스의 비밀 값(키·토큰·비밀번호)을 서버에 등록해야 할 때 |

## 안내 문구

**데이터 조회 요청은 제목과 내용 대신 항목 카드를 채운다.** 항목 종류는 WINUS 화면 · 우리펀드서비스 화면 · 엑셀(SQL) · 테이블 중 하나이고, 필요한 데이터마다 카드를 하나씩 추가한다. 카드마다 아래 칸에 넣을 값을 적어 준다.

| 칸 | 넣을 값 |
|---|---|
| 시스템, 화면 번호·이름 | 화면 항목. 사용자가 보던 화면의 번호와 이름 |
| 시스템, 테이블 이름 | 테이블 항목. 시스템을 모르면 「모르겠음」을 고르고 테이블 이름은 비워도 된다 |
| 엑셀 파일 또는 SQL | 엑셀(SQL) 항목. 사용자가 가진 SQL 이 있으면 이 칸에 붙여 넣는다 |
| 실제 동작 방식과 활용 예시 | 필요한 결과 열, 조건, 집계, 그 데이터를 어디에 쓰는지. 확인했지만 맞지 않았던 등록 쿼리 id 도 적는다 |
| 조회 권한 설정이 필요한가요? | 특정 팀·본부만 봐야 하는 데이터면 「필요」와 그 팀·본부 |

**그 밖의 유형은 제목과 내용을 준다.** 제목은 요청을 한 줄로 적는다. 내용에는 아래를 순서대로 적는다.

- 하던 작업과 멈춘 단계
- AX 팀에 요청하는 일
- 확인한 값: 저장소 이름, 컨테이너 이름, 대시보드 이름, 화면에 나온 오류 줄 그대로
- 이미 해 본 조치

**환경변수(env) 등록은 키 이름과 용도만 적는다.** 저장소 이름, 서비스 이름, 키 이름과 그 키로 코드가 하는 일을 적는다. 값은 사용자가 양식에서 직접 넣는다.

안내 문구 예시(제공 인프라):

```
문의 유형: 제공 인프라
제목: <본부> 대시보드 저장소 쓰기 권한 요청
내용:
- 하던 작업: <본부> 대시보드에 <기능> 기능을 올리다 GitHub 업로드에서 멈춤
- 요청: <조직>/<저장소> 저장소 쓰기 권한
- 확인한 값: 업로드 오류 "<오류 줄 그대로>"
- 해 본 조치: GitHub 로그인 다시 확인
```

## 지킬 것

- 비밀 값(접근 키, 비밀번호, 토큰, `.env` 의 값)을 안내 문구에 넣지 않는다. 값이 든 파일을 열지 않는다.
- 문의 서비스 주소가 열리지 않으면 사내망이나 VPN 연결을 확인하라고 알린다. 다른 연락 경로를 지어내지 않는다.
