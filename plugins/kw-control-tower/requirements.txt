# 문서 작업용 파이썬 라이브러리
#
# 버전 제약은 반드시 이유와 함께 적는다. 이유 없는 제약은 두지 않는다.
# 이 파일이 설치 목록의 정본이다. setup.ps1 은 여기를 읽는다.

# 엑셀을 읽고 쓴다
openpyxl

# 워드를 읽고 쓴다
python-docx

# 기존 PPT를 열어 내용을 바꾼다
python-pptx

# PDF에서 글자를 뽑아낸다
pypdf

# 기존 PPT·워드·엑셀·PDF의 내용을 읽어 낸다.
# 확장을 지정하지 않고 설치하면 해당 형식을 읽지 못한다. 확장 하나가 형식 하나에 대응한다.
# xls 는 구형 엑셀(.xls)용이며 xlsx 와 별개다 — 사내외 자료에 아직 흔해서 함께 넣는다.
# [all] 은 음성 인식과 외부 서비스까지 끌고 오므로 쓰지 않는다.
# 아웃룩 메일 파일(.msg)을 다룰 일이 생기면 extra 에 outlook 을 더하면 된다.
markitdown[docx,pptx,pdf,xlsx,xls]

# CSV 파일이 어떤 인코딩으로 저장됐는지 알아낸다.
# 사내에서 오가는 CSV는 대개 cp949(윈도 한국어)로 저장되는데, UTF-8로 읽으면 글자가 전부
# 깨지거나 아예 열리지 않는다. 사용자 눈에는 "클로드가 잘못했다"로 보인다.
# 바이트를 들여다보고 인코딩을 알려 줄 뿐이라 파일을 고치지 않는다. 부작용이 없다.
chardet

# 표 형태 데이터를 계산하고 정리한다.
# 판을 3.0 미만으로 묶는다. 이 제약은 그대로 둔다.
pandas<3.0
