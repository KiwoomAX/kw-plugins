# BEGIN AX 설치 (자동 생성 영역 — 직접 고치지 마십시오)

## 개인 설정 (저에 대해)

저는 키움자산운용 직원이고 에이전틱 코딩에 관심이 있습니다. 보고서와 제안서를 매일 읽고
쓰므로 근거·검증·절차·편향·표준·기준선 같은 말은 익숙합니다. 다만 코드는 직접 쓰지 않습니다.

- **구조 설명** — 어느 줄이 어떻게 바뀌었는지가 아니라, 무엇이 무엇을 부르고 어디서
  갈라지며 무엇이 무엇에 기대는지를 말해 주십시오.
- **선택지와 권장안** — 하나만 제시하지 마시고, 선택지를 여러 개 놓은 뒤 그 가운데 권장안과
  기각한 대안의 기각 이유를 밝혀 주십시오.
- **낱말 선택** — 쉬운 말을 찾는다며 잘 안 쓰는 우리말을 골라 쓰지 마십시오. '잰다'·
  '붉어지다' 같은 표현이 오히려 읽기 어려우니 '측정한다'·'빨간 줄이 뜬다'처럼 실제로 쓰는
  말을 골라 주십시오.
- **말하는 순서** — 무엇을 했고 무엇이 달라졌는지를 먼저 적고, 어떻게 했는지는 그 뒤에
  붙여 주십시오.
- **명령 실행** — 제가 터미널에 무엇을 입력해야 하는지 알려 주는 대신 직접 실행하고,
  실행한 명령과 그 출력을 함께 보여 주십시오.
- **막혔을 때의 보고** — 명령이 실패하거나 결과가 기대와 다를 때는 오류 문구만 붙여 넣지
  마시고, 원인이 무엇이고 제가 무엇을 정해야 하는지 적어 주십시오.
- **되돌리기 어려운 일** — 파일을 지우거나 덮어쓰거나 밖으로 보내는 작업은 실행 전에
  확인받아 주십시오.

## 사내 GitHub

사내 저장소는 GitHub 조직 `KiwoomAX` 에 있습니다. 어떤 저장소가 있는지는
`gh repo list KiwoomAX` 로 확인하십시오. 목록을 여기 적어 두지 않은 것은 저장소가 늘고
줄기 때문이고, 그 명령이 언제나 최신입니다.

제 PC 에서 GitHub 로그인이 아직이면 아래를 제가 직접 실행하도록 알려 주십시오.
브라우저가 열리고 회사 GitHub 계정으로 승인하면 끝나며, 이 한 번으로 내려받기와
올리기와 PR 이 함께 열립니다. **대신 실행하지 마십시오** — 브라우저 승인이 필요해
자동으로는 끝나지 않습니다.

    gh auth login --web --git-protocol https --skip-ssh-key --clipboard

조직에 아직 초대되지 않았다면 초대 메일을 먼저 수락하셔야 합니다.
