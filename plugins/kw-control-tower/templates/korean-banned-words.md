# 한국어 금지어 목록

답변과 산출물에 아래 왼쪽 단어를 쓰지 않는다. 오른쪽을 쓴다.

사람의 판단에 맡기지 않는다. 내보내기 전에 문자열로 검색해서 거른다. 코드와 파일 이름과
인용은 대상이 아니다. 산출물은 보고서·제안서·인수인계·발표자료처럼 사람이 읽으려고
만드는 문서를 말한다.

## 한자어를 고유어로 되돌린 것

쉬운 말을 찾는다며 어종을 바꾼 것이다. 한자어가 이미 좁은 뜻을 갖고 있어서 바꾸면
뜻이 넓어지고, 읽는 사람이 문맥으로 다시 좁혀야 한다.

```
재다 · 잰다 · 재는 · 재지 · 재어지다   →   측정 · 확인 · 관측 · 계산
짚다 · 짚는다 · 짚어                 →   지적 · 언급
훑다 · 훑어                         →   검토 · 확인
맞대다 · 맞댄                       →   대조 · 비교
띄우다 · 띄운다 · 띄워               →   실행 · 호출
굴리다 · 굴린다 · 굴려               →   실행 · 처리
쟁이다 · 쟁여                       →   축적 · 보관
가르다 · 가른다 · 갈라               →   구분 · 분리
```

## 무엇이든 가리킬 수 있는 넓은 말

대상의 이름을 대신해서 뜻의 범위를 넓힌다. 읽는 사람이 무엇을 말하는지 다시 찾아야 한다.

```
자리                →   그 대상의 이름을 그대로 쓴다
부분 · 영역          →   그 대상의 이름을 그대로 쓴다
경우                →   조건 · 상황
물음                →   질문
```

## 영어를 그대로 옮긴 것

문법은 맞는데 한국어에 없던 말이 된다.

```
걸음                →   단계
뿌리                →   원인 · 근본 원인
꼴                  →   형태 · 형식
갈래                →   종류 · 분기
갈림길 · 갈래 길     →   선택지
붉어지다 · 붉어진    →   실패
헛돌다 · 헛돈다      →   무의미
품이 들다 · 품이 든  →   수고 · 노력
각도                →   관점
```

## 뜻을 정하지 않고 지어낸 표현

```
회차 · 째 판 · 이번 판        →   무엇의 몇 번째인지 이름과 함께 적는다
낱말                        →   단어
버려야 하는 것 · 살아남는 것   →   버릴 것 · 남길 것
```

## 안내 문구

```
다 됐습니다     →   완료되었습니다
받아 가기       →   다운로드
새로 만들기     →   재생성
```

## 단어가 아닌 규칙

불릿 첫머리에 '오히려'를 쓰지 않는다. '중요한 것은' 으로 쓴다.

비유로 설명하지 않는다. 대상의 이름과 실제 동작을 그대로 적는다.
