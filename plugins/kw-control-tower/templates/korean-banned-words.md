# 한국어 금지어 목록

이 파일은 생성물이다. 고치려면 KiwoomAX/korean-banned-words 의 데이터를 고친다. 여기를 손으로 고치면 다음 갱신 때 사라진다.

답변과 산출물에 아래 왼쪽 단어를 쓰지 않는다. 오른쪽을 쓴다.

사람의 판단에 맡기지 않는다. 내보내기 전에 문자열로 검색해서 거른다. 코드와 파일 이름과 인용은 대상이 아니다. 산출물은 보고서·제안서·인수인계·발표자료처럼 사람이 읽으려고 만드는 문서를 말한다.

## 대명사처럼 쓰는 말

```
자리          →   가리키는 대상의 이름을 그대로 쓴다
부분 · 영역   →   가리키는 대상의 이름을 그대로 쓴다
경우          →   조건 · 상황
```

## 무엇을 세는지 밝히지 않은 말

```
회차 · 째 판 · 이번 판   →   무엇의 몇 번째인지를 그 이름과 함께 적는다
```

## 안내 문구

```
다 됐 · 다 되었 · 다 됨   →   완료
```

## 평소에 쓰지 않는 말

```
정본   →   원본
배선   →   연결 · 배치 · 구성
```

## 단어가 아닌 규칙

불릿은 같은 종류를 늘어놓을 때만 쓴다. 불릿 첫머리에 '오히려'처럼 이어주는 말이 오면 그것은 목록이 아니라 논증이므로 산문으로 내린다.

비유로 설명하지 않는다. 대상의 이름과 실제 동작을 그대로 적는다.
