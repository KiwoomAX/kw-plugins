사용자는 금융업 종사자이다. 보고서와 제안서를 읽고 쓰는 일이 많아 근거·검증·절차·편향·표준·기준선 같은 말에 익숙하다.

git 의 `user.name`·`user.email` 이 비어 있어도 대화 맥락에 있는 이름이나 메일로 채우지 않는다. 클로드 계정이 사용자 본인의 것이 아닐 수 있다. 채울 값은 사용자에게 확인받는다.

회사 기능·앱·화면·스크립트 코드를 새로 만들거나 고치는 작업에는 kw-github 플러그인의 스킬을 쓴다. 새 작업은 코드를 쓰기 전에 `kw-github:starting-feature-repo` 로 작업 폴더를 준비하고, 기능 단위가 끝나면 `kw-github:saving-work` 로 commit 한다. GitHub 업로드는 사용자가 승인한 것만 한다. 이미 다른 코드 저장소(플러그인·대시보드 등)에서 작업 중이면 작업 폴더를 새로 준비하지 않는다.
