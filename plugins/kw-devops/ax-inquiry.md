# AX 팀 문의 안내

스킬이 AX 팀에 요청이나 문의가 필요하다고 할 때 이 문서대로 안내한다. AX 팀은 요청을 AX 지원 문의 서비스로 받는다.

| 항목 | 값 |
|---|---|
| 주소 | `http://192.7.9.45/ax/` (사내망, 사내 계정으로 로그인) |
| 첫 화면 | 문의하기 양식. 로그인을 거치면 주소 뒤의 경로가 사라지므로 늘 첫 화면 주소로 안내한다 |

## 안내 순서

1. 사용자에게 AX 팀 문의가 필요하다는 사실과 이유를 알린다. 하던 작업에서 무엇이 멈췄는지, AX 팀이 해 줄 일이 무엇인지, 고를 문의 유형을 한두 문장으로 적는다.
2. "문의 초안을 작성해 드릴까요?" 라고 묻는다. 그렇다고 할 때만 초안을 쓴다. 아니라고 하면 쓰지 않는다.
3. 초안은 정해진 틀 없이 지금 상황에 맞게 쓴다. 아래 「양식 칸」은 양식이 받는 칸을 알려 주는 참고이고, 모든 칸을 채우거나 순서를 맞출 필요는 없다. 사용자가 고쳐 달라고 하면 그대로 고친다.
4. "문의 화면을 열까요?" 라고 묻는다. 그렇다고 하면 아래 명령으로 기본 브라우저를 연다. 아니라고 하면 열지 않는다.

   ```powershell
   Start-Process 'http://192.7.9.45/ax/'
   ```

5. 문의는 사용자가 양식에서 직접 보낸다. Claude 는 대신 보내지 않는다. 그다음 동작(멈출지, 다른 단계를 이어 갈지)은 이 문서를 연 스킬이 정한다.

## 문의 유형

부르는 스킬이 문의 유형을 정해 준다. 정해 주지 않았으면 아래 표로 고른다.

| 문의 유형 | 고르는 상황 |
|---|---|
| 데이터 조회 요청 (화면·엑셀·테이블) | 필요한 데이터를 읽는 등록 쿼리가 없어 새 쿼리 등록이 필요할 때 |
| 제공 인프라 | 저장소·화면 권한, 셸 변경, 포트·경로 등록, 샌드박스 공간처럼 AX 팀만 바꿀 수 있는 설정이 필요할 때. 다시 해도 계속 실패하는 서버·도구 오류를 알릴 때 |
| 기능 검토 문의 | 직접 만든 기능의 검토·배포·대시보드 이관을 요청할 때 |
| 환경변수(env) 등록 | 배포할 서비스의 비밀 값(키·토큰·비밀번호)을 서버에 등록해야 할 때 |

## 양식 칸

**데이터 조회 요청은 제목과 내용 대신 항목 카드를 받는다.** 항목 종류는 WINUS 화면 · 우리펀드서비스 화면 · 엑셀(SQL) · 테이블 중 하나이고, 필요한 데이터마다 카드를 하나씩 추가한다. 카드의 칸은 아래와 같다.

| 칸 | 넣는 값 |
|---|---|
| 시스템, 화면 번호·이름 | 화면 항목. 사용자가 보던 화면의 번호와 이름 |
| 시스템, 테이블 이름 | 테이블 항목. 시스템을 모르면 「모르겠음」을 고르고 테이블 이름은 비워도 된다 |
| 엑셀 파일 또는 SQL | 엑셀(SQL) 항목. 사용자가 가진 SQL 이 있으면 이 칸에 넣는다 |
| 실제 동작 방식과 활용 예시 | 필요한 결과 열, 조건, 집계, 그 데이터를 어디에 쓰는지. 확인했지만 맞지 않았던 등록 쿼리 id |
| 조회 권한 설정이 필요한가요? | 특정 팀·본부만 봐야 하는 데이터면 「필요」와 그 팀·본부 |

**제공 인프라와 기능 검토 문의는 제목과 내용을 받는다.** 내용에는 하던 작업과 멈춘 단계, AX 팀에 요청하는 일, 확인한 값(저장소·컨테이너·대시보드 이름, 화면에 나온 오류 줄 그대로), 이미 해 본 조치 중 상황에 맞는 것을 쓴다.

**환경변수(env) 등록은 제목 칸이 없다.** 제목은 「환경변수(env) 등록: <컨테이너>」로 자동으로 붙고, 요청 내용 칸은 선택이다. 양식은 아래를 받는다.

- 대상 컨테이너: 배포 목록에서 고른다. 처음 배포하는 서비스면 「신규」를 고르고 서비스 이름(영문 소문자·숫자·`-` 만), 배포 예정일, GitHub 저장소 주소를 적는다. AX 팀 논의 내역은 선택이다.
- `.env` 파일 하나: 값이 든 파일을 그대로 올린다. 키 파일(서비스 계정 JSON 같은 것)은 배포 스킬의 비밀 키 문서대로 먼저 `.env` 에 `<이름>_B64` 줄로 넣는다. 양식이 파일에서 키 이름을 읽어 목록에 보인다. 키 이름은 영문·숫자·`_` 로 쓰고 숫자로 시작하지 않으며, 겹치는 키가 있으면 보내지 못한다.
- 키별 용도(선택): 키마다 어떤 상황에 어떤 화면에서 무엇을 쓰기 위해 쓰는지 적는다.

파일을 다시 올리면 적어 둔 용도가 지워진다. 등록하지 않을 키가 목록에 보이면 그 줄을 지운 파일을 먼저 다시 올리고, 그다음 용도를 적으라고 알린다. 값은 초안과 양식의 글 칸에 적지 않는다.

## 지킬 것

- 비밀 값(접근 키, 비밀번호, 토큰, `.env` 의 값)을 초안에 넣지 않는다. 값이 든 파일을 열지 않는다.
- 문의 서비스 주소가 열리지 않으면 사내망이나 VPN 연결을 확인하라고 알린다. 다른 연락 경로를 지어내지 않는다.
