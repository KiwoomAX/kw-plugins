# AX 팀 등록 요청 메일의 모양

SKILL.md 의 「AX 팀에 등록 요청 보내기」에서 연다. 언제 보내는지와 스크립트를 부르는 법은 거기 있다.
여기는 두 요청의 제목과 본문 블록 순서와 고정 문장만 정한다.

**본문은 `outlook-email` general plain 형식의 JSON 이다.** `blocks` 에 블록을 순서대로 쌓는다. 블록
값 안에서는 `**굵게**` 만 쓴다. 백틱은 글자 그대로 찍힌다. 예시의 `<…>` 를 실제 값으로 바꾸고,
표의 행과 목록 항목은 개수에 맞게 늘리거나 줄인다.

**메일 문장은 개조식으로 쓴다.** 명사형으로 닫고 부연은 `—` 뒤에 잇고 나열은 `·` 로 가른다. 담당자에게
받아 채우는 값(용도·예상 실행 시간 같은 것)도 같은 형식으로 적는다.

## 환경변수 등록 요청

제목은 `[배포 등록 요청] 환경변수 — <저장소>` 로 한다.

| 차례 | 블록 | 담는 것 |
|---|---|---|
| 1 | `kv` | 저장소, 조직, 컨테이너, 자격증명, 요청자, 요청 시각 |
| 2 | `table` | 키 이름과 용도(코드가 그 키로 하는 일 한 줄) |
| 3 | `p` | 「첨부 있음 문장」이나 「첨부 없음 문장」 |
| 4 | `note` | 고정 문장 |

요청 시각은 `YYYY-MM-DD HH:mm KST` 로 적는다. 같은 날 두 통을 보내도 AX 팀이 구별할 수 있어야 한다.

**첨부 있음 문장** — `첨부 .env에 위 표의 키만 포함 — 키 이름 그대로 **env-<서비스>** 자격증명에 등록 요청`

**첨부 없음 문장** — `요청자 PC에서 값 첨부 실패 — 키 이름 그대로 **env-<서비스>** 자격증명에 등록 요청`

**note 고정 문장** — `첨부에 값이 없는 키는 요청자가 별도 전달 — 등록 완료 후 요청자에게 회신 요청`

```json
{
  "docTitle": "[배포 등록 요청] 환경변수 — <저장소>",
  "blocks": [
    { "type": "kv", "rows": [
      ["저장소", "<저장소>"],
      ["조직", "<조직>"],
      ["컨테이너", "<container_name>"],
      ["자격증명", "env-<서비스>"],
      ["요청자", "<담당자 이름>"],
      ["요청 시각", "<YYYY-MM-DD HH:mm> KST"]
    ]},
    { "type": "table", "head": ["키 이름", "용도"], "rows": [
      ["<키 이름>", "<코드가 이 키로 하는 일>"]
    ]},
    { "type": "p", "text": "첨부 .env에 위 표의 키만 포함 — 키 이름 그대로 **env-<서비스>** 자격증명에 등록 요청" },
    { "type": "note", "text": "첨부에 값이 없는 키는 요청자가 별도 전달 — 등록 완료 후 요청자에게 회신 요청" }
  ]
}
```

## 스케줄 등록 요청

SKILL.md 6단계가 가른 요청 종류마다 형식이 다르다.

### 컨테이너 실행형

제목은 `[배포 등록 요청] 스케줄 — <저장소> <서비스>` 로 한다.

| 차례 | 블록 | 담는 것 |
|---|---|---|
| 1 | `kv` | 저장소 주소, 브랜치, compose 파일, 덮어쓰기 파일, 프로젝트 이름, 서비스, 실행 주기, 실행 명령, 예상 실행 시간, 자료 경로 |
| 2 | `ol` | AX 팀이 할 일 |
| 3 | `note` | 프로젝트 이름 문장과, 「값은 첨부에 있음」이나 「값은 따로 전달」 |

할 일은 예시의 문장을 그대로 쓰고 `<…>` 만 바꾼다. compose 파일과 덮어쓰기 파일은 저장소 기준 경로로
적는다. 프로젝트 이름은 compose 의 `name:` 값이다. 실행 주기는 cron 식과 한국 시간 설명을 함께 적는다
(`0 6 * * *` — 매일 06:00 KST). 자료를 쓰지 않는 서비스는 자료 경로 행과 자료 폴더를 만드는 할 일을 뺀다.

**값은 첨부에 있음** — `비밀 값은 환경변수 등록 요청 메일의 첨부에 포함`

**값은 따로 전달** — `비밀 값은 요청자가 별도 전달`

`note` 는 `compose 프로젝트 이름이 Jenkins 배포와 같음 — 같은 compose 파일을 두 곳에서 사용` 뒤에 ` · ` 를 두고 위 둘 가운데 하나를 잇는다.

```json
{
  "docTitle": "[배포 등록 요청] 스케줄 — <저장소> <서비스>",
  "blocks": [
    { "type": "kv", "rows": [
      ["저장소 주소", "https://github.com/<조직>/<저장소>"],
      ["브랜치", "main"],
      ["compose 파일", "<compose 파일>"],
      ["덮어쓰기 파일", "<Jenkins 덮어쓰기 파일>"],
      ["프로젝트 이름", "<compose name 값>"],
      ["서비스", "<서비스>"],
      ["실행 주기", "<cron 식> — <한국 시간 설명>"],
      ["실행 명령", "docker compose -f <compose 파일> -f <Jenkins 덮어쓰기 파일> run --rm -T <서비스>"],
      ["예상 실행 시간", "<담당자가 답한 시간>"],
      ["자료 경로", "/home/chshin84/opt/<저장소 이름>/data"]
    ]},
    { "type": "ol", "items": [
      "서버에 저장소 클론",
      "자료 폴더 생성 — mkdir -p /home/chshin84/opt/<저장소 이름>/data",
      "체크아웃 루트에 .env 배치 — 이 compose 파일이 요구하는 키 전부 포함",
      "compose나 Dockerfile이 쓰는 certs/를 체크아웃에 배치",
      "체크아웃 폴더에서 실행 명령과 같은 파일로 빌드 — docker compose -f <compose 파일> -f <Jenkins 덮어쓰기 파일> build <서비스>",
      "crontab에 실행 주기와 실행 명령 등록 — 명령은 체크아웃 폴더에서 실행",
      "체크아웃 갱신 때마다 위 빌드 재실행"
    ]},
    { "type": "note", "text": "compose 프로젝트 이름이 Jenkins 배포와 같음 — 같은 compose 파일을 두 곳에서 사용 · 비밀 값은 환경변수 등록 요청 메일의 첨부에 포함" }
  ]
}
```

### 주소 호출형

제목은 `[배포 등록 요청] 스케줄 — <저장소> <주소 경로>` 로 한다.

| 차례 | 블록 | 담는 것 |
|---|---|---|
| 1 | `kv` | 저장소, 컨테이너, 호출 주소, 실행 주기, 실행 명령, 예상 실행 시간 |
| 2 | `ol` | AX 팀이 할 일 |
| 3 | `note` | 고정 문장 |

호출 주소는 서버 안에서 부르는 `http://127.0.0.1:<호스트 포트><주소 경로>` 다. 실행 명령의 `-m` 은 예상 실행
시간보다 넉넉한 초로 적는다. 라우트가 비밀 키를 헤더로 확인하지 않으면 명령의 `-H` 와 키를 쓰는 할 일을 뺀다.

**note 고정 문장** — `저장소 체크아웃·빌드 불필요 — Jenkins가 띄운 컨테이너의 주소만 호출`

```json
{
  "docTitle": "[배포 등록 요청] 스케줄 — <저장소> <주소 경로>",
  "blocks": [
    { "type": "kv", "rows": [
      ["저장소", "<저장소>"],
      ["컨테이너", "<container_name>"],
      ["호출 주소", "http://127.0.0.1:<호스트 포트><주소 경로>"],
      ["실행 주기", "<cron 식> — <한국 시간 설명>"],
      ["실행 명령", "curl -fsS -m <초> -H \"Authorization: Bearer $<키 이름>\" http://127.0.0.1:<호스트 포트><주소 경로>"],
      ["예상 실행 시간", "<담당자가 답한 시간>"]
    ]},
    { "type": "ol", "items": [
      "crontab에 실행 주기와 실행 명령 등록",
      "명령의 $<키 이름>에 **env-<서비스>** 자격증명의 같은 키 값 사용"
    ]},
    { "type": "note", "text": "저장소 체크아웃·빌드 불필요 — Jenkins가 띄운 컨테이너의 주소만 호출" }
  ]
}
```
