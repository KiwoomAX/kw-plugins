# 문서 작성 기준

이 저장소의 문서, 코드 주석, 화면 문구를 쓸 때 따르는 기준이다. 용어는 이 파일에서만 정하고,
다른 문서는 이 파일을 따른다.

## 독자

이 저장소의 글은 비개발자 직원이 읽는다고 보고 쓴다. 그래서 CS 용어는 직원이 업무에서 실제로
쓰는 말로 옮긴다. 다만 옮기면서 일상에서 쓰지 않는 말을 새로 만들지 않는다. 예전에 지문, 문지기,
안내판, 자국, 몸통 같은 말이 그렇게 생겨 오히려 읽기 어려웠다.

## 원칙

- **이름은 그대로 둔다.** 명령, 파일 이름, 설정 항목 이름, 외부 프로그램의 오류 원문은 용어가 아니라
  이름이다. `git commit`, `settings.json`, `enabledPlugins` 를 옮기지 않는다.
- **클로드 코드 화면에 나오는 제품 용어는 그대로 둔다.** 플러그인, 마켓플레이스, 스킬, 훅, 세션,
  출력 스타일이 그렇다. 직원이 화면에서 보는 말과 문서의 말이 같아야 한다.
- **나머지 CS 개념은 아래 용어표의 일상어로 쓴다.** 표에 없는 개념이 나오면 표에 먼저 더한다.
- **일상어로 옮기기 어려운 구현 세부는 문장에서 뺀다.** `info/refs`, `pkt-line` 같은 것은 코드
  이름으로만 남긴다.
- **한 개념에는 한 이름만 쓴다.** 같은 것을 두 이름으로 부르면 읽는 사람은 다른 것으로 읽는다.
- **클로드에게만 가는 문구도 같은 용어를 쓴다.** 클로드가 그 말을 그대로 사용자에게 전하기 때문이다.

## 용어표

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 동기화 | `scripts/sync.ps1` 이 이 PC를 목록에 맞게 고치는 일 | 맞춤 |
| 목록 | `manifest.json`. 무엇을 설치하고 무엇을 정리할지 적은 파일이다. 다른 목록은 "라이브러리 목록", "허용 목록"처럼 앞에 이름을 붙인다 | 선언, 사내 목록, 정본, 목록 파일(hooks.json 을 가리킬 때) |
| 세션 점검 훅 | 세션이 시작할 때 실행되는 `hooks/session-check.ps1`. 이 PC가 목록과 다른 곳을 찾고, 있으면 동기화를 호출한다 | 알림 훅, 점검 훅, 세션 시작 훅, 세션 시작 알림 |
| 점검 | 세션 점검 훅이 이 PC가 목록과 다른 곳을 찾는 일 | 감지 |
| 마켓플레이스 | 플러그인을 내려받는 곳. 클로드 코드의 제품 용어다 | 배포처, 발행처 |
| 내려받은 마켓플레이스 | 마켓플레이스의 코드 저장소를 PC에 내려받은 폴더(`~/.claude/plugins/marketplaces/<이름>`) | 사본, 클론 |
| 설치 폴더 | 클로드 코드가 설치한 플러그인 파일을 두는 폴더(`~/.claude/plugins/cache`) | 사본, 캐시 |
| 복사본 | 원본을 복사해 둔 파일. CLAUDE.md 가 불러오는 `kw-ax/claude-md-ko.md` 와 다른 코드 저장소에서 복사해 온 코드가 여기에 해당한다 | 사본 |
| 백업 | 고치기 전에 남겨 둔 파일(`.bak`) | 사본 |
| 이전에 복사해 둔 스킬 | 설치기가 예전에 스킬 폴더에 복사해 둔 스킬 | 스킬 사본 |
| 설치된 플러그인 | 이 PC에 설치되어 있는 플러그인 | 설치본 |
| 업데이트 | 설치된 플러그인이나 내려받은 마켓플레이스를 최신 버전으로 바꾸는 일 | 옮기다, 갱신, 받아오다 |
| 최신 버전이 아니다 | 설치된 것이 GitHub 의 최신 버전보다 오래되었다 | 뒤처지다 |
| 최신 버전 확인 | 세션 점검 훅이 `curl.exe` 로 GitHub 의 최신 버전 번호만 읽는 일 | 원격 커밋 읽기 |
| 활성화, 비활성화 | 플러그인을 쓰게 하거나 쓰지 않게 하는 일 | 켜다, 끄다, 꺼지다 |
| 시작, 재시작 | 클로드 코드나 세션을 여는 일 | 켜다 |
| 폐기 | 더 이상 쓰지 않기로 한 플러그인, 마켓플레이스, 스킬, 훅을 각 PC에서 정리하는 일 | 은퇴 |
| 전환 | 이전 구조에서 새 구조로 옮겨 가는 작업 | 이행 |
| 사내 지침 | 템플릿 `claude-md-ko.md` 의 내용. CLAUDE.md 의 AX 블록이 불러온다 | 문안, 사내 문안 |
| 제한 시간 | 동기화나 명령이 실행될 수 있는 최대 시간 | 상한, 예산, 시간 제한 |

| 잠금 폴더 | CLAUDE.md 를 두 플러그인이 동시에 고치지 않도록 만드는 폴더(`<파일>.lock`) | |

| 시작 표시 줄, 끝 표시 줄 | AX 블록의 `# BEGIN AX` 줄과 `# END AX` 줄 | 마커 |
| 가짜 python3 | 파이썬이 설치되지 않은 윈도우에서 `python3` 명령이 가리키는 파일. 파이썬이 아니라 마이크로소프트 스토어로 연결한다 | 안내판, 리디렉터, 별칭 |
| 실제 위치 | 링크가 가리키는 파일의 위치 | 실물 |
| 플러그인 ID | `<플러그인 이름>@<마켓플레이스 이름>` | 번호표 |
| 훅 자체의 실행 시간 | 세션 점검 훅의 실행 시간에서 프로그램을 띄우는 시간을 뺀 것 | 몸통 |
| 출처가 사라진 플러그인 | 등록된 어느 마켓플레이스에도 없는 설치된 플러그인 | 고아 |
| 지킬 조건 | 설계가 반드시 지키기로 정한 조건 | 계약 |
| 기준 | 여러 곳 가운데 옳다고 보는 하나 | 정본, 진실 |
| 잘못된 경고 | 문제가 없는데 문제라고 알리는 것 | 거짓 양성 |
| 허용 목록 | 허용하는 것만 적은 목록 | 화이트리스트 |
| 단어 | 명령이나 출력의 한 단어 | 낱말 |
| 검토자 | 설계 문서를 읽고 지적만 남기는 별도의 클로드 | 렌즈 |

### 코드 저장소와 버전

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 코드 저장소 | git 저장소(repository) | 레포, 저장소 |
| 체크포인트 | 코드 저장소에 변경을 저장하는 일과 그 단위(commit). 명령 `git commit` 은 그대로 둔다 | 커밋 |
| 버전 | 체크포인트가 버전을 가리킬 때의 말. 예: 최신 버전, 버전 번호(체크포인트 번호의 앞 7자리) | 원격 커밋, 새 커밋 |
| 업로드 | 내 체크포인트를 GitHub 에 올리는 일(push) | 푸시 |
| 내려받다 | GitHub 의 새 체크포인트를 받아 내 파일에 반영하는 일(pull) | 받아오다 |
| 받아 두다 | 받기만 하고 내 파일에는 반영하지 않는 일(fetch) | |
| GitHub | 원격 코드 저장소가 있는 곳 | 원격 |
| git 명의 | git 체크포인트에 남는 이름과 메일(`user.name`, `user.email`) | |

### 실행과 오류

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 프로그램 | 실행 중인 프로그램(process) | 프로세스 |
| 오류로 멈춘다 | 오류를 내고 그 자리에서 멈춘다(throw) | 던지다 |
| 오류를 무시한다 | 오류를 알리지 않고 지나간다 | 삼키다 |
| 형식 오류 | JSON 같은 데이터 파일을 읽지 못하는 것 | 파싱 오류, 안 읽힌다 |
| 문법 오류 | 스크립트를 읽지 못하는 것 | 파싱 오류 |
| 테스트용 가짜 프로그램 | 테스트에서 진짜 프로그램 대신 실행하는 것(stub) | 스텁 |
| 터미널 | 명령을 입력하는 창(shell) | 셸 |
| 여러 번 실행해도 결과가 같다 | 이미 된 것은 건너뛰고, 두 번 실행해도 결과가 같은 성질 | 멱등 |

## 숫자와 표기

- 개수와 기간은 아라비아 숫자로 쓴다. 8단계, 14일, 11곳, 4개이지 여덟, 열나흘, 열한, 넷이 아니다.
- 차례는 "4차 검토", "3차 초안"처럼 쓴다.
- 한국어 문장 안에서는 클로드, GitHub, 윈도우, 공개, 다음 날로 쓴다. Claude, 깃허브, 윈도, 퍼블릭,
  다음날과 섞지 않는다.

## 메시지 형식

- 직원이 화면에서 보는 안내는 합니다체로 쓴다.
- 오류 기록 파일에 남는 문구와 스크립트가 오류로 멈출 때의 문구는 개조식으로 쓴다. 명사형으로
  끝내고, 앞에 무엇이 어디서 틀렸는지를 둔다. 예: `JSON 형식 오류: <경로>`.

## 그대로 두는 말

- 클로드 코드 제품 용어: 플러그인, 마켓플레이스, 스킬, 훅, 세션, 출력 스타일
- 이미 사무 환경에서 쓰는 말: 템플릿, 백업, 레지스트리, 환경 변수, 인코딩, 스크립트, 되돌리기, 잠금,
  폴더, 경로, 명의
- 재시작 안내의 첫 줄 `kw-control-tower: 다시 켜야 새 버전이 적용됩니다.`. disciplined-coder 와
  합의한 형식이라 두 플러그인이 함께 바꿔야 한다.
- AX 블록의 시작 표시 줄 문구. 바꾸면 모든 PC의 CLAUDE.md 블록이 한 번씩 다시 쓰인다.
